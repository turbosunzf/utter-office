四条主路径（须点通）

1首页「派单」→ picker(dispatch) → 档案 或工作台
2我的「数字员工」→ 名册 → 档案 →「与他对话」→ 工作台
3工作台 Rail 切员工；「全部」→ 名册；阻断条「去绑定」→ 档案能力 Tab
4我的「秘书设置」→ 秘书设置 → picker(default) → 回设置；中央按钮见 录音 Overlay
